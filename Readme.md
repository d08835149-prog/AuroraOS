AuroraOS is a browser-based desktop environment built with **HTML, CSS, and Vanilla JavaScript**.

Inspired by modern desktop operating systems, AuroraOS provides an interactive desktop experience featuring draggable windows, customizable wallpapers, multilingual support, and live weather information.

## ✨ Features

- 🚀 Boot animation with startup sound
- 🖥️ Interactive desktop environment
- 🪟 Draggable and resizable application windows
- 🌤️ Live weather using the Open-Meteo API
- 📍 Automatic location detection
- 🌅 Sunrise & sunset information
- 🕒 Live system clock
- 🎨 Wallpaper customization
- 💾 Preferences saved with Local Storage
- 🌍 Multi-language support (English, Korean, Spanish, Hindi)
- 📖 Aurora Journal
- ✉️ Translation feedback option
- ✨ Smooth window animations
