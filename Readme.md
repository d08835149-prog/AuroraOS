AuroraOS is a browser-based desktop environment built with HTML, CSS, and JavaScript.

Inspired by modern operating systems, AuroraOS provides a clean desktop interface with draggable windows, customizable wallpapers, and live weather information.

---

## Features

- 🚀 Boot animation with startup sound
- 🖥️ Interactive desktop environment
- 🪟 Draggable and resizable windows
- 🌤️ Live weather based on the user's location
- 📍 Automatic location detection
- 🎨 Wallpaper customization (saved with Local Storage)
- 📖 Aurora Journal application
- 🕒 Live clock
- ✨ Smooth window animations

---

## Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
- Open-Meteo API
- Browser Geolocation API
